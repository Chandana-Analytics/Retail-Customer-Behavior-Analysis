# Dataset Information

This project uses the **Online Retail II** dataset from the UCI Machine Learning Repository.

* **Dataset:** Online Retail II
* **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
* **Format used:** CSV
* **Original dataset period:** December 2009 – December 2011

The raw and cleaned CSV files are not included in this repository because of their large file sizes.

Please download the original dataset from the UCI source linked above to reproduce the analysis.
